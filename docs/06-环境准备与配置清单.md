## 二、开工前需要你处理的 3 件事

### 2.1 启动 Docker Desktop + 调内存（✅ 已完成 2026-10-14：已代启动，内存 7.75GiB 已达标，无需调整）

1. 打开 Docker Desktop（应用启动后等待鲸鱼图标变绿）；
2. **设置内存 ≥ 6G**：Settings → Resources → Memory 调到 6G 或以上（Nacos + RabbitMQ + MySQL 合计要吃 3-4G，给足余量）；
3. 验证：终端执行 `docker info | grep "Total Memory"`，确认 ≥ 6GiB。

> 可选：如果拉取镜像慢，Settings → Docker Engine 里配置镜像加速（`registry-mirrors`），保存后 Apply & Restart。

### 2.2 确认 IDE 使用 JDK 17（重要）

检测发现你机器上有**两个 JDK**：
- 终端默认：**17.0.20.1**（Homebrew，✅ 项目就用它）
- 系统另有：**Oracle JDK 24**（`/usr/libexec/java_home` 当前指向它 ⚠️）

**风险**：Spring Boot 3.2 官方支持 JDK 17-21，若 IDEA 默认选了 24 可能遇到兼容报错。开工前在 IDEA 里确认：

```
File → Project Structure → SDK = 17
Settings → Build Tools → Maven → Runner → JRE = 17（或 Project SDK）
```

可选：在 shell 配置（`~/.zshrc`）里固定 Java 17，一劳永逸：
```bash
export JAVA_HOME=$(/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home)   # brew 安装路径
# 验证
java -version   # 应显示 17.x
```

其余工具全部就绪，无待办。

## 六、常见问题

| 问题 | 处理 |
|------|------|
| Docker 拉镜像慢/超时 | Docker Desktop → Settings → Docker Engine 配置镜像加速后 Apply & Restart |
| Nacos 容器启动失败/反复重启 | 内存不足——回看 2.1 调到 ≥6G；查看日志 `docker logs <nacos容器>` |
| 端口被占用 | 运行时本检测（`lsof -iTCP:端口 -sTCP:LISTEN`）排查；如 3306 被本机 MySQL 占用，停掉本机服务或改 compose 端口映射 |
| IDEA 报 JDK 版本错误 | 回看 2.2，把 Project SDK / Maven Runner 都设为 17 |
| `jq: command not found`（如换机器） | `brew install jq` |
